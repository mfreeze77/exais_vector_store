Section 201.3, Terms defined in other codes, is hereby deleted in its entirety and the following provision shall be substituted therefor:
(a) Where terms are not defined in this code and are defined in other codes, such terms shall have the meanings ascribed to them in those codes.
Any reference to the following codes in the IEBC will be deleted and replaced with the following codes:
• International Property Maintenance Code is replaced with the property maintenance code, adopted in Chapter 8.60 TMC.
• International Building Code is replaced with the building code, adopted in Chapter 14.20 TMC.
• Electrical Code is replaced with the electrical code, adopted in Chapter 14.30 TMC.
• International Plumbing Code is replaced with the plumbing code, adopted in Chapter 14.35 TMC.
• International Fire Code is replaced with the fire code, adopted in Chapter 14.40 TMC.
• International Mechanical Code is replaced with the mechanical code, adopted in Chapter 14.50 TMC.
• International Residential Code is replaced with the residential code, adopted in Chapter 14.55 TMC.
• International Energy Conservation Code is replaced with the energy conservation codes, adopted in Chapter 14 TMC.
(b) Any reference to the sections in Chapter 11 of the 2015 International Fire Code will be deleted and replaced with applicable sections of the IEBC unless the building code official, in consultation with the fire code official, determines that the public’s health and safety is better served by following the applicable provisions of the Life Safety Code adopted at TMC 14.45.010 .
(Ord. 20344 § 12, 2-15-22.)
