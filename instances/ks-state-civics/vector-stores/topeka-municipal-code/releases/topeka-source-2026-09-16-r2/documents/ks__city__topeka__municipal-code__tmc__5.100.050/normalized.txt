Before any license may be issued under this chapter, the application for the license must be certified by the Code Enforcement Director as complying with the City ordinances. Prior to certification by the Code Enforcement Director, the premises must be inspected and approved by the Code Enforcement Director, or a duly authorized representative, as complying with all the provisions of this chapter and all other applicable ordinances of the City. (Code 1981 § 25-52. Code 1995 § 98-100.)
