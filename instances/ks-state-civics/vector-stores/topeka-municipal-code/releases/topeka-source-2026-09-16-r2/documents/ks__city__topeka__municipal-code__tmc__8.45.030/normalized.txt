It shall be unlawful for any person to start a fire or allow any person to start a fire in any trash burner, incinerator, metal barrel or drum, except as provided in TMC 8.45.060 ; provided, however, that gas or electric fired incinerators which have been approved by the Fire Chief or Fire Marshal shall be exempt from the provisions of this section. (Ord. 17049 § 1, 12-10-96. Code 1981 § 16-118. Code 1995 § 70-163.)
