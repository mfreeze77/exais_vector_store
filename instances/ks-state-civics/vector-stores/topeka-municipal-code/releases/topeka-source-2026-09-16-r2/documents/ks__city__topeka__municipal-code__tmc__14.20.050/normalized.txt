The amendments to the International Building Code adopted by TMC 14.20.010 shall be as set out in this article. All references to section and chapter numbers in the text of this article shall be construed as if followed by the words “of the International Building Code,” unless clearly indicated to the contrary. (Ord. 18882 § 6, 5-15-07. Code 1981 § 10-60. Code 1995 § 26-136.)
