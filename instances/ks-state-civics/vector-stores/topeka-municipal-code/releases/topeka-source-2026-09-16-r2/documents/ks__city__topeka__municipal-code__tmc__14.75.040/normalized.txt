The Code Enforcement Director is hereby authorized, empowered and directed to establish such exceptions to the numbering system described in this chapter as may be made necessary by the irregular routing of any streets, avenues and other highways. Such exceptions shall be shown on a plat made under the direction of the Code Enforcement Director and kept on file in the office of the Code Enforcement Director. (Code 1981 § 10-506. Code 1995 § 26-634.)
