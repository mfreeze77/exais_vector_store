At least one copy of the Uniform Mechanical Code as adopted in TMC 14.50.010 shall be on file with the City Clerk to be available for inspection by the public at all reasonable business hours. All administrative departments of the City charged with the duty of enforcement of this code shall be supplied, at the cost of the City, such number of copies of the code as may be deemed necessary by the Code Enforcement Director. (Ord. 20195 § 2, 7-23-19.)
