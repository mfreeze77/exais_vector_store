Section 102.3 is deleted in its entirety and the following provisions are substituted therefor:
Repairs, additions or alterations to a structure, or changes of occupancy, shall be done in accordance with the building code in Chapter 14.20 TMC, the international energy conservation code in Chapter 14.80 TMC, the international fire code in Chapter 14.40 TMC, the mechanical code in Chapter 14.50 TMC, the international residential code in Chapter 14.55 TMC, and the plumbing code in Chapter 14.35 TMC.
(Ord. 20625 § 3, 12-16-25; Ord. 19899 § 6, 4-15-14. Formerly 8.60.050.)
