The Governing Body has determined that structures exist within the City that are so deteriorated, dilapidated, or so out of repair as to be dangerous, unsafe, unsanitary or otherwise unfit for human habitation or occupancy such that it is unreasonable to repair the structure. The Code Official identified in TMC 8.60.030 is designated to exercise the powers prescribed in this chapter. (Ord. 20145 § 2, 10-2-18.)
