(d) Dimensional Requirements. See Chapter 18.230 TMC.
(e) Nonconforming Uses. See Chapter 18.220 TMC.
(f) Site Plan Regulations. See Chapter 18.260 TMC.
(g) Landscaping Requirements. See Chapter 18.235 TMC.
(h) Subdivision Regulations. See Chapters 18.30 through 18.45 TMC. (Ord. 19921 § 124, 9-23-14.)
