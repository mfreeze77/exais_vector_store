Any applicant dissatisfied with the ruling of the Code Enforcement Director in denial of or conditions imposed upon the issuance of a permit under this article may, within 10 days of the Code Enforcement Director’s ruling, ask for a review of the application by the City Council. The Council upon majority vote may grant the permit which has been denied by the Code Enforcement Director. (Code 1981 § 40-402. Code 1995 § 130-127.)
