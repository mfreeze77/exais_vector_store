Any reference to the following codes in the IECC will be deleted and replaced with the following codes:
(a) International Property Maintenance Code is replaced with the property maintenance code, adopted in Chapter 8.60 TMC.
(b) International Building Code is replaced with the building code, adopted in Chapter 14.20 TMC.
(c) Electrical Code is replaced with the electrical code, adopted in Chapter 14.30 TMC.
(d) International Plumbing Code is replaced with the plumbing code, adopted in Chapter 14.35 TMC.
(e) International Fire Code is replaced with the fire code, adopted in Chapter 14.40 TMC.
(f) International Mechanical Code is replaced with the mechanical code, adopted in Chapter 14.50 TMC.
(g) International Residential Code is replaced with the residential code, adopted in Chapter 14.55 TMC.
(h) International Energy Conservation Code (Residential) is replaced with the energy conservation code, adopted in Chapter 14.80 TMC. (Ord. 20343 § 5, 2-15-22.)
